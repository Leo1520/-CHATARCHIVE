Acerca de ChatArchive

ChatArchive es una aplicación web progresiva (PWA) diseñada para importar, visualizar y conservar tus chats exportados de WhatsApp en un entorno seguro y privado.

Privacidad Garantizada
Tus archivos no se envían a ningún servidor en la nube ni se comparten con servicios de analíticas.
  • Compatible con Android, Windows y Web
  • Funciona sin conexión a internet (Offline)
  • Listo para desplegar en GitHub Pages
